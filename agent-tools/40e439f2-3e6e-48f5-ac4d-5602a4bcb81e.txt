**@sanderrenes** commented · May 23, 2025 at 1:01pm · edited

> Edits: libre3 was added, since Boris mentions same issue with fsl3
> 
> @Jan1758 thanks for the reminder, I wanted to check some things.
> The statement that is causing problems was introduced with version 3.3.0
> 
> in 3.2.0.4 the relevant bit of code is:
> if (data[i].recalculated > 38) {
> ...
> change = now.recalculated - then.recalculated
> val avgDel = change / minutesAgo * 5
> 
> and in 3.3.0 this becomes:
> if (data[i].value > 39 && !data[i].filledGap) { // if (data[i].recalculated > 38) {
> ....
> change = now.recalculated - then.recalculated
> val avgDel = change / minutesAgo * 5
> 
> The release notes did not make clear to me why the extra condition was added (or why the check move to value instead of recalculated)
> 
> I then tried to find the filledGap variable, but got a bit stuck. It appears to be set deep in the code, I can follow it back till "inMemoryGlucoseValue.kt" where I also found this comment:
> 
> /**
> * Simplified [app.aaps.core.data.model.GV] for storing in memory and calculations
> * It may correspond to GlucoseValue value in db
> * but because of 5 min recalculations and smoothing it may not
> */
> 
> That seems to be our issue. Since my FSL2 reports on a 2-minute interval, there is never a measure exactly 5 minutes ago. To get a 5-minute measure, you have to fill the gap between 4 and 6 minutes by definition. 
> This 2 minute interval appears particular to this sensor.
> 
> So, is this what causes your error? if you have FSL2 - EU version like me, then very likely.
> Can you solve it?
> yes, either make the same adjustment as I did in your own fork, or use my fork (i am still running on it, works fine with me)
> 
> Can we solve it for everyone? 
> That is harder. It seems it is particular to fsl sensors. I don't know why this if-condition was added, but if it is for safety reasons, it might not be wise to bluntly remove it for everyone. We could work around it, for instance with an if condition that says something along the lines:
> 
> if (data[i].value > 39 && (!data[i].filledGap || SourceSensor=="Libre2" || SourceSensor=="Libre3"))
